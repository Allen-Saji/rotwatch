# Rotwatch - brand

## Name

**Rotwatch**

Coined from "rot" (bitrot) + "watch" (vigilance). Owns the moment you catch
your own tooling going stale before it bites you.

## Tagline

"Catch the rot before your agent does."

Alternate: "Your skills shouldn't rot in silence."

## Promise

Rotwatch tells you which of your agent skills are telling the agent to run
commands that no longer exist - and shows you the fix before you approve it.

## Direction

Minimalist and institutional. Mono-forward, technical, no ornament. The product
is a lint tool for agent skills; the brand should read like careful
instrumentation, not a marketing page.

Light theme only. Dark text on light background. Distinctiveness comes from a
single accent and the type pairing, never from going dark.

## Palette

Light-first, with a derived dark mode from the same seeds.

The primary green is the "rot" signal - decay caught and contained. The amber
accent marks the finding/attention state.

## Typography

- **Mono (display + code + labels):** JetBrains Mono
- **Sans (body):** Inter

The product is about command lines and diffs; monospace leads. Body text stays
sans for readability. All diffs and CLI output are rendered in JetBrains Mono.

## Voice

- Matter-of-fact, direct, no filler.
- No "AI slop" phrasing, no em dashes, plain ASCII hyphens only.
- Findings are stated as facts with evidence, never as accusations.
- The tool reports what it can prove and says "unverifiable" when it cannot.

## Wordmark

Simple wordmark: **rotwatch** set in JetBrains Mono, lowercase, with the "w"
opening slightly widened. Optional glyph: a `~` tilde decay motif - a bracket
or command prompt with the trailing character fading into a tilde, suggesting
decay caught in time.

## Do

- Lead with a concrete finding, not a slogan.
- Show the diff next to the evidence.
- Keep the light theme and mono-forward look consistent.

## Don't

- Don't go dark for its own sake.
- Don't anthropomorphize the agent ("your agent forgot").
- Don't use scare framing about security; this is drift, not an attack.
